## 软件简介
本监视器可以持续监控Gnirehtet的连接，并在出错时自动重启Gnirehtet以重新连接。
监视器的的编程语言为PowerShell。

## 入口文件说明

本目录包含三个入口文件，分别对应不同的使用场景：

### 1. （Gnirehtet自带的启动入口） - 直接启动
- **功能**：直接启动 Gnirehtet 代理服务，不包含自动重连等功能

### 2. monitor.bat - 双窗口监视器
- **功能**：会打开一个PowerShell 窗口显示监控信息，代理窗口独立于监视器(默认最小化)。
- 兼容性：最低 PowerShell 2.0，推荐 5.0 或更高

### 3. single-monitor.bat - 单窗口监视器
- **功能**：在同一窗口中启动和监控 gnirehtet 进程
- 兼容性：最低 PowerShell 1.0，推荐 2.0 或更高

## 使用步骤

### 1. 准备工作
- 确保 Android 设备已启用 USB 调试模式，一般会在开发者模式里。
- 将 Android 设备通过 USB 连接到计算机，并启用 USB 调试(注意：数据线和充电线不是同一个东西，数据线包含充电功能，但充电线无法传数据)
- 确保计算机已安装 ADB 驱动(ADB、Gnirehtet、本监视器处于同一文件夹即可)

### 2. 安装客户端应用
- 首次使用时，需要在 Android 设备上安装 gnirehtet.apk
- 可以通过 ADB 命令安装：`adb install gnirehtet.apk`

### 3. 启动代理服务
- 根据需要选择合适的入口文件运行
- 运行后，Android 设备会收到 VPN 连接请求，点击 "确定" 允许

### 4. 验证连接
- 手机的通知栏会显示连接状态。

## 常见问题排查

### 1. 端口占用错误
- 症状：启动时显示 "端口 31416 被占用"
- 解决方案：一般来说监视器会自动检测并处理端口占用问题

### 2. 设备连接问题
- 症状：一直断连
- 解决方案：去找根稳定的数据线，或者换个接口

### 3. VPN 连接问题
- 症状：Android 设备上没有收到 VPN 连接请求
- 解决方案：
  - 确认 gnirehtet.apk 已正确安装
  - 检查设备的 VPN 权限设置

### 4. 网络连接问题
- 症状：代理服务已启动，但设备无法访问网络
- 解决方案：
  - 检查计算机的网络连接是否正常
  - 尝试重启代理服务

### 注意事项
- 本项目并不包含 Gnirehtet 本体，所以你需要去自己下载一个。
- 我没有写重启上限，所以理论上它会无限重启，不用的时候关掉以节省资源。
- 为了避免神秘BUG，路径不要有中文。

### 如何检查 PowerShell 版本
在 PowerShell 中运行以下命令：
```powershell
$PSVersionTable.PSVersion
```
